## 🎨 Asset Creation Guidelines

### Screenshot Standards
- **Resolution:** 1920x1080 for full screens, 1200x800 for sections
- **Format:** PNG for UI, JPG for photos
- **Compression:** TinyPNG for optimization
- **Annotations:** Red boxes, numbered callouts (Figma/Sketch)
- **Naming:** `section-name-description.png`

### Video Tutorial Standards
- **Resolution:** 1920x1080 @ 30fps
- **Length:** 5-15 minutes per tutorial
- **Format:** MP4 (H.264)
- **Audio:** Clear voiceover, no background music
- **Captions:** Required for accessibility
- **Tool:** Loom, Camtasia, or ScreenFlow
- **Naming:** `tutorial-name-vX.mp4`

### Code Example Standards
- **Syntax Highlighting:** Prism.js
- **Copy Button:** Required on all code blocks
- **Comments:** Explain complex logic
- **Testing:** All code must be tested
- **Formatting:** WordPress Coding Standards
