
**3. Customize Content**
- Replace plugin name
- Adjust feature categories
- Modify element types
- Update settings sections
- Adapt time estimates

**4. Adjust Timeline**
Based on:
- Plugin complexity
- Number of features
- Existing documentation
- Team availability

### Plugin Type Adjustments

#### Page Builder Addon (like EAW)
- **Focus:** Element documentation
- **Heavy phases:** 4, 6
- **Time:** 50-70 hours

#### E-commerce Plugin (like PJ Product Filter)
- **Focus:** Configuration, integrations
- **Heavy phases:** 5, 6, 8
- **Time:** 40-60 hours

- **Focus:** Workflows, organization
- **Heavy phases:** 3, 5, 6
- **Time:** 30-50 hours

#### Theme Documentation (like Axiom)
- **Focus:** Customization, templates
- **Heavy phases:** 4, 5, 7
- **Time:** 40-60 hours

## 📊 Content Standards

### Writing Style
- **Tone:** Professional but friendly
- **Voice:** Second person ("you")
- **Tense:** Present tense
- **Length:** Short paragraphs (2-3 sentences)
- **Lists:** Use bullets and numbers generously

### Code Standards
- **Language:** WordPress Coding Standards
- **Comments:** Explain complex logic
- **Testing:** All code must work
- **Syntax Highlighting:** Prism.js or similar

### Visual Standards
- **Screenshots:** 1920x1080 (full), 1200x800 (sections)
- **Format:** PNG for UI, JPG for photos
- **Compression:** Always optimize
- **Annotations:** Red boxes, numbered callouts

### Video Standards
- **Resolution:** 1920x1080 @ 30fps
- **Length:** 5-15 minutes
- **Format:** MP4 (H.264)
- **Audio:** Clear voiceover
- **Captions:** Required
